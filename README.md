# Eatropy

物理学生が、キッチンで起きる現象を物理の視点で読み解きます。

🔗 https://eatropy.github.io/Eatropy/

## 構成

- `index.html` — トップページ(記事一覧)
- `about.html` — About ページ
- `posts/` — 記事ページ
- `css/style.css` — スタイル

## 記事を追加するには

`posts/` に新しい HTML ファイルを作成し、既存の記事をコピーして編集してください。`index.html` の「Latest」セクションにリンクを追加すると、トップページに表示されます。
